## 1. 📋 Store-Eintrag (Texte für die Play Console)

### **App-Name** (24 / 30 Zeichen)
```text
7secs Torsong Soundboard
```

### **Kurzbeschreibung** (74 / 80 Zeichen)
```text
Dein schnelles Handball- & Sport-Soundboard für Torsongs mit 7s Countdown.
```

### **Vollständige Beschreibung** (Max. 4000 Zeichen)
```text
7secs ist das ultimative Soundboard für Hallensprecher, Trainer, Betreuer und Fans im Hallensport – speziell optimiert für Handball, Fußball und Hallenturniere!

Spiele mit nur einem Fingertipp den individuellen Torsong des jeweiligen Spielers ab. Der integrierte 7-Sekunden-Countdown sorgt für das perfekte Timing beim Jubel, bevor das Spiel weitergeht.

🔥 TOP-FEATURES:
• One-Tap Soundboard: Blitzschnelle Reaktion – 1 Klick und der Torsong läuft sofort ab.
• 7-Sekunden Jubel-Countdown: Visueller Countdown und Waveform-Animation für optimales Hallen-Timing.
• Team-Verwaltung: Verwalte mehrere Teams (z. B. 1. Herren, Damen, Jugend) mit eigenen Spielerlisten.
• Eigene Sounds zuweisen: Weise jedem Spieler individuelle MP3s oder Jingles zu.
• Schnelle Bearbeitung: Spieler und Torsongs lassen sich direkt in der App anpassen und sortieren.
• 100% Offline-fähig: Funktioniert zuverlässig in jeder Sporthalle ohne Internetverbindung.
• Keine Werbung, kein Tracking: Voller Fokus auf das Spiel.

Mache jedes Tor zum Hallen-Highlight mit 7secs!
```

## 5. 🚀 Release-Bundle (.aab) erstellen & signieren

### Schritt 1: Einmalig Keystore erstellen (falls noch nicht vorhanden)
Führe folgenden Befehl im Terminal aus:
```bash
keytool -genkey -v -keystore release.keystore -alias sevensecs-key -keyalg RSA -keysize 2048 -validity 10000
```
*(Merke dir das vergebene Passwort gut!)*

### Schritt 2: `build.json` im Ordner `src-cordova/` anlegen
Kopiere `src-cordova/build.json.example` nach `src-cordova/build.json` und trage dein Passwort ein:
```json
{
  "android": {
    "release": {
      "keystore": "release.keystore",
      "storePassword": "DEIN_KEYSTORE_PASSWORT",
      "alias": "sevensecs-key",
      "password": "DEIN_KEY_PASSWORT",
      "keystoreType": ""
    }
  }
}
```

### Schritt 3: Release AAB bauen
```bash
npm run cordova-build-android-release
```
Das fertige Bundle (`.aab`) findest du anschließend unter:
`src-cordova/platforms/android/app/build/outputs/bundle/release/app-release.aab`

Lade diese `.aab`-Datei in der Google Play Console unter **Produktion** oder **Geschlossener Test** hoch!
